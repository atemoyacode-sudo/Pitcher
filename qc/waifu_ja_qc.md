# 品質チェック：学習データ2（Anime Waifu Personality Chat 日本語訳）

- 対象：`学習データ2_日本語.json`（1,722件、Gemma 4 E4B で翻訳）
- 元データ：`anime-waifu-personality-chat.json`（[scryptiam/anime-waifu-personality-chat](https://huggingface.co/datasets/scryptiam/anime-waifu-personality-chat)、CC BY 4.0）
- 修正版：`学習データ2_日本語_clean.json`（1,691件）。`python3 qc/clean_waifu_ja.py` で作成し、翻訳ファイル本体は変更していない

## 結論

訳は全体に自然な日本語で、属性ごとの口調（ツンデレの「べ、別に」、クーデレの淡々とした「〜わ」、元気っ娘の「〜だよ！」など）も描き分けられている。問題はボクっ娘の一人称と、元データに混ざっていた解説文が中心で、どちらも機械的に直せた。

## 機械的なチェック

| チェック | 結果 |
|---|---|
| 件数・並び順が元データと一致 | 1,722件、1件ずつ対応 |
| 属性名の訳の一貫性 | 20属性すべて1対1（例：tsundere → ツンデレ） |
| 空欄・訳し残しの英語・ハングル・簡体字 | 0件 |
| 仮名を含まない行（中国語化の疑い） | 0件 |
| 「翻訳：」「注：」などの訳注の混入 | 0件 |
| 長さ（訳文の文字数 ÷ 原文の文字数） | 中央値 0.52（極端に短い・長いものなし） |
| ツンデレのどもり（「I-I」→「わ、私」） | 原文71件 → 訳81件（保たれている） |

## 見つかった問題と対応

| 問題 | 件数 | 対応 |
|---|---:|---|
| ボクっ娘の一人称が「私」になっている | 39 | 「ボク」に置き換え（39件すべて一人称の用法だったことを確認済み） |
| セリフではなく属性の解説文（「ツンデレというのは…」）| 20 | 学習データから外し、`学習データ2_属性説明.json` に保存 |
| 解説文を除くとセリフが1件しかない属性（ウンデレ、ニャンデレなど9属性） | 9 | 外す |
| 元データの時点で重複しているセリフ | 2 | 後のほうを外す |
| 文法が壊れた語尾（「認めないわから。」） | 3 | 手で直した |
| "Did you expect anything less?"（当然でしょ？）を「それ以下を期待していたの？」と直訳 | 1 | 手で直した |
| 訳文の末尾に JSON の断片が残っている（「…だからねっ！」}, {」）| 15 | 取り除いた（最初のチェックでは見落としていて、学習後のモデルが同じ断片を出力したことで気づいた） |

## 直していないもの

- **ダンデレのどもりが消えている**：「Y-You don’t have to... I-I appreciate it...」→「そんなに私のことを気にかけてくれなくてもいいんだけど……でも……あのね、感謝してるよ……」。「……」や「あのね」で気弱さは残っているので、そのままにした。
- **"nothing less" の直訳（「それ以下は受け入れないわ」）**：残り3件は意味が通るので直していない。
- **一人称**：ボクっ娘以外は全属性で「私」（またはなし）に統一されていて、「俺・僕」の混在はない。姫デレ・神デレは「わたくし」などにする案もあるが、元データに区別がないのでそのままにした。

## 学習データとして使うときの提案

- `学習データ2_属性説明.json` の解説文は、学習時のキャラ設定文（system プロンプト）の素材になる。属性の説明をそのまま設定文に入れれば、属性ごとの差をモデルに伝えやすい。
- 修正版の各行には `source_row`（元データの行番号）と `source_en`（英語の原文）を残してあるので、あとから原文と突き合わせられる。
