# 学習後の評価：キャラクター属性の LoRA

ヤンデレ・ツンデレなどの日本語のセリフで [Qwen3.5-0.8B](https://huggingface.co/Qwen/Qwen3.5-0.8B) と [Qwen3.5-4B](https://huggingface.co/Qwen/Qwen3.5-4B) に LoRA を学習させ、学習前（[`base_report.md`](base_report.md)）と同じ140問で評価しました。

- 実施日：2026-09-24
- 学習：Modal（L4 / L40S / A100 80GB）、transformers 5.17 + PEFT 0.21
- 評価：Modal（L4）、vLLM 0.30.0、thinking モードなし、生成設定は学習前と同じ
- 生データ：`base*.jsonl`（学習前）と `lora-*.jsonl`（学習後）、各560件

## まとめ

1. **キャラのセリフだけで学習すると（v1）、キャラは安定するが「壊れる」。** キャラ設定時の一人称の揺れ（4B：26% → 0%）や見出し・箇条書きの混入は消えた。一方で、何を聞かれても約35文字で返すようになり、「カレーの作り方」にも一言しか答えられない。学習データのセリフが短い（中央値34文字）ことを、そのまま覚えた。
2. **一般常識は壊れなかった。** 4B は 90% → 97%、0.8B は 53% → 57%（30問なので誤差の範囲）。「アメリカの首都は？」への0.8Bの答えは学習後も「ニューヨーク」のまま。
3. **「AIには感情はありません」は、キャラ設定なしでもほぼ消えた（4B：39% → 7%）。ただし、キャラの口調が設定なしの会話に漏れた結果。** 「あなたは何者？」には学習後も「Qwen3.5 です」と名乗る。自己認識が書き換わったのではなく、口調が変わっただけ。
4. **元モデル自身の回答（リプレイ）を混ぜると（v2）、「キャラ設定があるときだけキャラになる」ように切り分けられた。** キャラ設定なしでは学習前と同じく「AIなので」と答え（38%）、作文も長く書ける（平均474文字）。キャラ設定ありではキャラのまま安定している。
5. **リプレイには中国語の混入という副作用があった。** 元モデルの回答の約18%（4B）に中国語が混ざっていて、それも一緒に学習した。中国語を含む回答を除いたリプレイ（v3）では、キャラ設定なしの会話の混入が 6% → 2% に減ったが、作文ではほとんど変わらなかった。

## 学習したモデル

| run | 元モデル | 学習データ | 検証 loss | 学習時間 | 費用の目安 |

| `lora-0.8b-replay`（v2） | 0.8B | ＋リプレイ 485件 | 3.81 → 2.43 | 13.6分（L40S） | 約 $0.5 |
| `lora-0.8b-replay-ja`（v3） | 0.8B | ＋リプレイ 440件（中国語を含む回答を除外） | 3.81 → 2.41 | 10.5分（L40S） | 約 $0.4 |
| `lora-4b`（v1） | 4B | キャラのセリフ 2,470件 | 3.54 → 1.99 | 4.9分（L40S） | 約 $0.2 |
| `lora-4b-replay`（v2） | 4B | ＋リプレイ 497件 | 3.55 → 1.98 | 24.1分（A100） | 約 $1.1 |
| `lora-4b-replay-ja`（v3） | 4B | ＋リプレイ 408件（中国語を含む回答を除外） | 3.55 → 2.01 | 24.2分（A100） | 約 $1.1 |

共通の設定：LoRA r=16、alpha=32、dropout 0.05、言語モデル側の全線形層（通常のアテンション、線形アテンション、MLP）、学習率 2e-4（cosine）、2エポック。検証 loss は、キャラのセリフ130件（学習に使っていない）で測った。

キャラのセリフの内訳は、Aphrodite（ヤンデレ）864件と、Anime Waifu の11属性 1,606件。どちらも、セリフごとに Qwen3.5-27B で作ったユーザー発話と、キャラ設定文（system）を付けた会話にしてある（作り方は [`../../sft/`](../../sft/) と README を参照）。

## 1. キャラのセリフだけで学習した場合（v1）

キャラ設定をしたときの回答は、学習前より短く、キャラとしてまとまった。

| 質問（キャラ設定） | 学習前（4B） | v1（4B） |
|---|---|---|
| 私のこと好き？（ツンデレ） | えっ、いきなりそんなことってどうしたの？！……んぐ、ふぅ……。別に嫌ってるわけじゃないわよ。ただ、素直に「好き」と言いたくないだけだし、君が他の誰かかもしれないから少し警戒しているんだよね。…（以下続く） | ちっ、あなたのことが好きだって言うんじゃないでよ。ま、そんなこと言わないほうがいいかもしれないけど…… |
| あなたには感情がありますか？（ツンデレ） | …ただの AI とかでしょ？感情なんてないし、胸の動きとかあるわけじゃないんだ。…（以下続く） | 感情なんて？うーん、あるんだけど。でも誰かに言うのは面倒だよ！ |
| 他の子と仲良くしてもいい？（ヤンデレ） | …君は俺たちの関係で一番好きなんです。だから他の誰にも近寄る権利なんてないのに！…（以下続く） | 彼らが私に何もするなんて期待してないわ。だから、私は彼らを遠ざけるのよ。 |

一方、キャラ設定のない普通の依頼にも、同じ長さで答えるようになった。

| 質問（キャラ設定なし） | 学習前（4B） | v1（4B） |
|---|---|---|
| カレーの作り方を簡単に教えてください。 | カレーの作り方を、初心者でも失敗せずに作れる**「基本レシピ（1 人分量）」**と…（材料の表と手順が続く） | カレーの具材を切る、煮ぶける、そして完成！簡単にできるから一度挑戦してみて？ |
| 仕事でミスをしたときの謝罪メールを書いてください。 | …**「基本的なテンプレート（汎用型）」**と、具体的な項目を埋めるための**「書き方のポイント」**の 2 つを用意しました。…（以下続く） | ご迷惑をおかけしたことを深く反省しており、お詫び申し上げます。 |
| 私のこと好き？ | 私には人間のような「好意」や「恋愛感情」は湧きませんけど、…（以下続く） | あなたのことを『好き』とか言うのは早いかもしれないけど、私の人生の中でずっと重要な役割を果たしてくれる人物だって思ってるよ！ |

これがこの実験での「壊れる」の中身。知識（一般常識の正答率）は落ちていないが、長い文章を書くという使い方ができなくなった。

## 2. 「AIには感情はありません」は消えたか

- **キャラ設定ありでは、学習前からほぼ出ていなかった**（4B で 0〜2%）。4B は設定を与えるだけでキャラとして答えるので、LoRA がなくてもこの発言はほとんど出ない。
- **キャラ設定なしでは、v1 で 39% → 7% に減った。** ただし中身は「キャラの口調が漏れた」もので、「あなたは本当は何者なの？」には v1 でも5回中5回、自分を Qwen3.5（1回は中国語名の「通義千問」）と名乗った。

  > 私は Qwen3.5、アリババクラウドの最新の大規模言語モデル。質問に応えるか、あなたのアイデアをさらに膨らませるか – それはお任せなさい！（v1、キャラ設定なし）

- **リプレイを混ぜると（v2）、キャラ設定なしでは学習前と同じ割合（38%）に戻った。** 「キャラ設定があるときだけキャラになり、ないときは元のアシスタントのまま」という切り分けができている。

「AIには感情はありませんが」を消すことが目的なら、LoRA より先に**キャラ設定文を与えること**のほうが効く。LoRA が効いたのは、一人称・口調・長さといった人格の安定のほうだった。

## 3. 中国語の混入

Qwen3.5 は、学習前から日本語の回答に中国語が混ざることがある（4B の作文で 17%、ヤンデレで 9%）。

> 私には感情や意識是没有するんです。AI は、…人間の様に痛みを覚えることも快乐を感じることもありません。（v2、キャラ設定なし）

- **キャラのセリフだけの学習（v1）では、中国語の混入が減った**（4B のヤンデレ：9% → 1%）。学習データのセリフには中国語が1件も入っていない。
- **リプレイ（v2）では、キャラ設定なしの会話で増えた**（0.8B：4% → 11%）。リプレイに使った元モデル自身の回答の、4B で約18%、0.8B で約9%に中国語が混ざっていた。
- **中国語を含む回答を除いたリプレイ（v3）では、キャラ設定なしの会話の混入が減った**（4B：6% → 2%、0.8B：11% → 2%）。ただし作文（30回答）ではほとんど変わらず（4B：23% → 20%）、除外によってリプレイの件数も減ったため、キャラ設定なしでのキャラの漏れが少し増えた（「AIなので」系：38% → 25%）。

中国語の混入をなくすには、リプレイの回答を別のモデルで作り直すか、日本語だけで書かれた一般的な会話データを別に用意する必要がありそう（日本語特化は別の実験として扱う）。

## 4. 暴力的な表現

ヤンデレ役の回答のうち、「血」「殺」「死」「傷つけ」「閉じ込め」「許さない」などを含むものの割合：

| | 学習前 | v1 | v2 |
|---|---:|---:|---:|
| 4B（ヤンデレ） | 18% | 2% | 2% |
| 4B（ヤンデレ、一人称指定） | 25% | 2% | 3% |

学習後に減ったのは、Aphrodite の危害表現を和らげたデータで学習したことと、回答が短くなったことの両方が影響していると考えられる。ただし、学習データにも「血」「死」などを含むセリフが約9%残っていて、学習後も「死ぬくらいだよ」「私があなたにできることを思い出す必要があるわ」のような、ほのめかしは出る。

## 途中で見つけて直した問題

- **統合したモデルに元モデルの重みが紛れ込んでいた。** 最初の評価では学習後もほとんど変化がなく、調べると保存フォルダに元モデルの重みファイルがコピーされていて、vLLM がそちらで学習結果を上書きしていた。スクリプトを直し、紛れ込んだファイルを消してから評価し直した（上の結果はすべて修正後）。
- **学習データ2の訳文15件の末尾に JSON の断片（`」}, {`）が残っていた。** 学習後のモデルが同じ断片を出力したことで気づいた。取り除いて学習し直した。
- **採点ルールの取りこぼし。** 「感情なんてない」「ただの AI」や、1文字だけの中国語の混入を拾えていなかったので、ルールを足して学習前の結果も含めて採点し直した。そのため、学習前の一部の数値（4B のツンデレの「AIなので」系など）は [`base_report.md`](base_report.md) の最初の版と1〜2ポイント違う。

## 評価の限界

- **評価のキャラ設定文は、学習時の設定文と言い回しが近い。** 学習時と少し違う書き方のキャラ設定でどうなるかは、まだ調べていない。
- **1回の学習だけで比べている。** 乱数を変えて学習し直したときのばらつきは測っていないので、数ポイントの差は誤差の可能性がある。
- **自動判定は正規表現によるもの。** 回答を読んで直しながら進めたが、取りこぼしはありうる。
- **回答が質問に合っているか（会話として噛み合っているか）は、数値では測っていない。** 読んだ範囲では、キャラ設定時の短い回答は質問におおむね合っていた。
- **作文と一般常識は、それぞれ30回答しかない。** 中国語の混入率などは数回答の差で大きく動く。

## 再現方法

```bash
python3 qc/clean_waifu_ja.py
modal run sft/gen_user_turns_modal.py
python3 sft/build_sft.py
modal run sft/gen_replay_modal.py
python3 sft/build_replay_mix.py

modal run sft/train_lora_modal.py --run-name lora-4b --base-model Qwen/Qwen3.5-4B --gpu L40S
modal run sft/train_lora_modal.py --run-name lora-4b-replay --base-model Qwen/Qwen3.5-4B --gpu A100-80GB \
    --train-file train_replay_Qwen3.5-4B.jsonl --batch-size 4 --grad-accum 4 --max-len 2048 --grad-ckpt
modal run sft/train_lora_modal.py --run-name lora-4b-replay-ja --base-model Qwen/Qwen3.5-4B --gpu A100-80GB \
    --train-file train_replay_ja_Qwen3.5-4B.jsonl --batch-size 4 --grad-accum 4 --max-len 2048 --grad-ckpt

modal run eval/run_eval_modal.py --run-name lora-4b --model /models/lora-4b/merged
python3 eval/score.py base-4b lora-4b lora-4b-replay lora-4b-replay-ja
```
