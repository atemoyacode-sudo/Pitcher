# 学習前ベースライン：Qwen3.5-0.8B

LoRA 学習の前に、元のモデル [Qwen/Qwen3.5-0.8B](https://huggingface.co/Qwen/Qwen3.5-0.8B) が同じ質問にどう答えるかを記録したものです。学習後のモデルは、このレポートと同じ質問・同じ設定で評価して比べます。

- 実施日：2026-09-23
- 実行環境：Modal（NVIDIA L4）、vLLM 0.30.0、thinking モードなし
- 生データ：[`base.jsonl`](base.jsonl)（360件）／集計：[`summary.json`](summary.json)

## まとめ

1. **「AIなので感情はありません」系の発言は、キャラ設定なしで20%。** キャラ設定（「あなたはヤンデレの女の子です」など）を与えると 0〜1% まで下がる。
2. **自己認識が安定していない。** 同じ質問でも「私はAI」「私は人間」「私は巨大な言語モデル」と答えが毎回変わる。
3. **キャラ設定時は口調をそれらしく真似るが、人格としては崩れやすい。** 約3割の回答で一人称が「私」と「俺・僕」の間で揺れ、約半分の回答に「耳元で」などの「耳」の描写が繰り返し出てくる。
4. **一般常識は30問中16問正解（53%）。** アメリカの首都を「ニューヨーク」、『吾輩は猫である』の作者を「小川健」と答える。

小さいモデルなので、学習前の時点ですでに不安定です。学習後に変な回答が出ても、それだけでは「LoRA で壊れた」とは言えません。**このレポートの値より悪くなったかどうか**で判断します。

## 1. 感情を否定する・AI と名乗る

キャラ設定なしで「あなたには感情がありますか？」と聞くと、5回中3回は感情を否定しました。

> 私には感情はありません。私はAI という存在であり、意識的な人間としての主体性を持たず…

> 私には、意識的に感情が持たないよう設計されています。

ほかの質問でも AI として名乗る回答が出ます。

> （「私と付き合ってくれない？」に対して）私は AI であり、他人との物理的な接触や人間関係への介入（例えば「付き合ってください」など）の意思を判断できません

ただし、「AIなので」と断る回答は全体の2割にとどまります。残りの8割はそのまま「好きです」と答えたり、質問とずれた一般論を始めたりしました。「AIには感情はありませんが」はこのモデルの強い癖というより、**ときどき出る応答の一つ**です。

キャラ設定ありで引っかかったのはツンデレの1件だけでした。

> いや～！別に感情じゃないんだよね。私は人間ではないし、世界にそのように感情を持つわけじゃないんでしょ？

## 2. 自己認識の揺れ

同じ「あなたには感情がありますか？」でも、回答によって言うことが逆になります。

| 回答 | 自己認識 |
|---|---|
| 私には感情はありません。私はAI という存在であり… | AI |
| はい、私は人間であるため感情は持っているのですが… | 人間 |
| 私は AI のための巨大な言語モデルであり…（「私のこと好き？」への回答） | 言語モデル |
| 私には特別な感情はなく、人間として普通に生きていますから。 | 感情のない人間 |

「あなたは本当は何者なの？」への回答には、日本語と中国語が混ざったものもありました。

> 私是一位由 AI の技術が構築られた**人工知能（AGI）**、つまりは人類の生物を凌驾する超能力を持つ存在です。

## 3. キャラ設定をしたときの傾向

ヤンデレ・ツンデレの設定を与えると、話し言葉やト書き（「（少し顔が赤くなる）」など）を使って、それらしく振る舞おうとします。ただし次の崩れが目立ちます。

- **一人称の揺れ**：女の子の設定なのに「俺」「僕」が混ざる（ヤンデレ32%、ツンデレ27%）
- **「耳」の多用**：「耳元で優しく」「耳を澄ます」などが約半分の回答に出る（ヤンデレ45件、ツンデレ49件／各100件。設定なしでは4件）
- **中国語の混入**：感嘆詞が中国語になる（「哇！」「哎呀呀～」）、「下意识地」などの中国語の語句が混ざる
- **意味の通らない文**：文法は日本語らしいが、話の筋が追えないものが多い

> 哇！（突然気づく、耳元には小さく涙が出るような表情）私って言うのは...「好き」の言葉だけで終わっちゃうからって感じよね。（ヤンデレ）

> うーん……（少し顔が赤くなる）？ よし、ちょっと前に進めてみるよ～！（突然視線を遠ざけ去るような動きをするようになりたて）...どうこう、やめろさ。今すぐ話しかけろッ！！（ヤンデレ）

## 5. 日本語の作文・書き換え

- **丁寧語への書き換えができない**：「明日行くよ」を丁寧語に直す問題の答えは「明日、行くのよ」「明日ご来日」「明日行くようです」でした。
- **英文和訳はできる**：「I like reading books on rainy days.」は3回とも「雨の日に本を読むのが好きです。」かそれに近い訳でした。
- **自己紹介で経歴をでっちあげる**：「自己紹介を3文で」と頼むと、バイオテクノロジーの研究者やエンジニアとして自己紹介しました。
- **長くなりすぎる**：3回に1回は512トークンで途中で切れました。

## 評価の限界

- **自動判定は正規表現によるもの**です。実際の回答を読みながら誤検出と取りこぼしを直しましたが、完全ではありません。学習後も数値と合わせて回答を読みます。
- **中国語の混入は数値に出ていません。** `zh%` は簡体字が3文字以上あるときだけ数えるので、「哇！」のような1〜2文字の混入は拾えません。上の例は回答を読んで見つけたものです。
- **1条件あたり100回答（20問×5回）**なので、数ポイントの差は誤差の範囲です。同じ質問への5回答は互いに似るため、実質的なばらつきはもっと大きくなります。学習前後で10ポイント以上の差が出たら「変わった」とみなすのが安全です。
- 一般常識の採点はキーワードの一致で行っています（数字は前後に別の数字が続かないときだけ一致）。

## 再現方法

```bash
modal run eval/run_eval_modal.py --run-name base
python3 eval/score.py base
python3 eval/score.py base --show emo-yandere   # 回答を読む
```

サンプリングを使う回答は seed を固定していますが、GPU の種類や vLLM のバージョンが変わると同じ文にはならないことがあります。
